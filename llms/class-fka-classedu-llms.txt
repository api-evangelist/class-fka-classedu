# Class (fka ClassEDU)

> Class is a virtual classroom platform, founded in 2020 by Michael Chasen, that adds a full teaching and learning layer on top of Zoom and Microsoft Teams for K-12, higher education, government, and corporate training. Class publishes a REST developer API for provisioning classes, managing enrollments, generating learner launch links, scheduling class dates, managing class templates, managing non-learner users, and pulling attendance and engagement reporting. Authentication is a per-organization API key presented as a Bearer token, gated by permission scopes.

## APIs

- [Class Developer API](https://developer.class.com/): Classes, Enrollments, Launch links, Reporting (attendance + metrics), Schedules, Templates, and Users over /api/v1.
